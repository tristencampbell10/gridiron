---
name: Player image matching
description: Avoiding incorrect player photos when resolving ESPN athlete records.
---

Do not select ESPN athlete records by normalized name alone. Verify the intended player using team and position, and use the core athlete record when search omits an older player.

**Why:** Public ESPN roster and search results can include multiple football athletes with identical names. A name-only map silently selected incorrect receiver photos.

**How to apply:** When adding or refreshing headshots, examine duplicate matches rather than letting the last result overwrite earlier records. Do not change the app's roster assignments merely to match a current external roster.
