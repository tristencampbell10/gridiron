# Gridiron Hub on Replit

## Run the app

- The **Start application** workflow runs `npm run dev` on port `5000`.
- To run a production build, use `npm run build`.

The app uses local demonstration data when Supabase is not configured. Persistent authentication and user data require `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` to be configured in Replit Secrets.
